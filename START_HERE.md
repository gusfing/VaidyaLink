## 🎯 Quick Start (30 Seconds)

```bash
cd frontend
npm run dev
```

Open: **http://localhost:3000/document-scan-demo**

---

## 🎤 Test Voice Processing

### Steps:

1. Click **"Voice Recording"** tab
2. Select a language (try **Hindi**)
3. Click **"Start Recording"**
4. Speak for 5-10 seconds
5. Click **"Stop Recording"**
6. Click **"Process Recording"**
7. **View results!**

### What You'll See:

- Transcription in your selected language
- Confidence score (92%)
- Extracted medical entities:
  - Chief Complaint
  - Symptoms
  - Duration
  - Severity
- FHIR integration notice

---

## 📄 Test Document Scanner

### Steps:

1. Click **"Upload Document"** tab
2. Click **"Sample 1 (Vivek M)"** or **"Sample 2 (New)"**
3. Click **"Upload & Process"**
4. Watch processing stages
5. **View results!**

### What You'll See:

- OCR text extraction

- Conditions and symptoms
