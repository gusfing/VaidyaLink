# Screenshots Directory

This directory contains all the UI screenshots and QR code for the VaidyaLink prototype.

## Required Images

Please add the following images to this directory:

1. **qr-code.png** - QR code for accessing the live prototype
2. **scan-prescription.png** - Screenshot of the prescription scanning screen with live AI analysis
3. **ai-summary.png** - Screenshot of the AI clinical summary dashboard
4. **health-passport.png** - Screenshot of the health passport with ABHA ID integration
5. **health-timeline.png** - Screenshot of the health timeline with FHIR export option
6. **records-library.png** - Screenshot of the records library interface
7. **voice-interface.png** - Screenshot of the multilingual voice interface

## Image Guidelines

- Format: PNG or JPG
- Recommended width: 1080px (mobile screenshots)
- Ensure no sensitive patient data is visible
- Use placeholder/demo data only
